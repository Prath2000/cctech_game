# Definition of Ready / Done
**Ready** (task can be picked):
- [ ] What/why clear; done-when check written
- [ ] Size set; dependencies linked and none open
**Done:**
- [ ] done-when met; tests pass (if any)
- [ ] Reviewed (small/big); verify.md filled
- [ ] Shipped to deploy.level (if >= L1); backlog task closed
- [ ] Handoffs moved into the change folder
